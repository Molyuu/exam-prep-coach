**路径约定（先读这条）**：脚本在 skill 装载目录里，不在学生工作区。先 `export SKILL=<加载 skill 时给出的 Base directory>`（如 `~/.codex/skills/exam-prep-coach`），再用 `python3 "$SKILL/scripts/xxx.py"` 调用；写成 `scripts/xxx.py` 会在工作区里找不到文件（exit 2）。
**P1 入库**：`python3 "$SKILL/scripts/pdf_prepare.py" <PDF...> --out markdown/ [--dpi 160] [--json]` → 每页渲染到 `<out>/_pages/<stem>-pNN.png`（处理页面旋转，单边 ≤4000px），打印绝对路径与转写目标 `<out>/<stem>.md`。**不抽文本层**：由 agent 逐页读图转写，看不清标「（?）」，禁止猜写 LaTeX。退出码：0 全部成功 / 1 部分 PDF 失败（损坏、加密）/ 2 参数或缺 swiftc。
**P4.5 审查**：`python3 "$SKILL/scripts/audit_scan.py" <工作区>/ai_study [--strict]` → 机械扫描 `$$`/`$` 成对、`\left`\right 配对、花括号与环境配对、详解每题是否给「答案」、禁词、「同型」引用是否含年份与题号、审查报告是否存在。无硬错误只是"可以开始盲解"，**不能替代盲解复核**（见 `references/audit.md`）。交付前加 `--strict`。
**P5 自检**：`python3 "$SKILL/scripts/check_coverage.py" <工作区>/ai_study [--partial | --strict] [--json]`（默认扫当前目录）核 ①题号↔详解 ②S/A 考点覆盖与空壳小节 ③Day 分节对齐 ④`markdown/` 原始卷子非空 ⑤错题表与 AGENTS.md。①②③④ 是硬失败（exit 1），⑤ 只 [WARN]；**exit 0 且无 [FAIL] 才可交付**；交付前用 `--strict` 跑一遍（提示项全部升级为硬失败，包括错题表与审查报告）。做 P0–P3 阶段时不要加 `--strict`，那时本来就没有讲解/习题，必然失败。按天滚动交付的中间天用 `--partial`：② 里还没写到的 S/A 考点降为 [WARN]（空壳小节仍是 [FAIL]）；最后一天改用 `--strict`。两者同时给 → exit 2。
