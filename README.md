# exam-prep-coach

**一个让 AI 帮你考前突击的 skill。** 喂它往年真题或模拟卷，它反推考点与重点、排出可执行的复习计划，并产出知识点讲解、分层习题集和逐题详解。

> 目标函数是**分数**，不是理解。默认学生零基础、时间紧。

适用对象：期中/期末/考研/资格证等有明确考试日期的场景，尤其是「还有 N 天，这门课我一点没学」的情况。

---

## 它解决什么问题

大多数复习建议是「按教材顺序系统学习」——时间够才成立。时间不够时，真正的问题是：

1. 这张卷子到底考什么？哪些反复出现？
2. 每类题值几分？零基础能拿到几成？
3. 剩下 N 天，先学哪个、明确放弃哪个？
4. 学会了怎么算会了？考场上第一行写什么？

这个 skill 把上面四步做成固定流程，并且强制每个产出都能被检验（题号对得上、考点全覆盖、每天有可测量的验收）。

## 安装

DeepSeek Harness 会扫描 `~/.dsh/skills/<name>/SKILL.md`：

```bash
git clone https://github.com/Molyuu/exam-prep-coach.git ~/.dsh/skills/exam-prep-coach
```

其他读取 `SKILL.md` 的工具（如 Claude Code）放到各自的 skills 目录即可，格式兼容。

装好后无需配置，skill 会出现在会话的 skill 列表里。

## 怎么用

自然语言触发：

```text
我还有 7 天考高数期中，卷子发你，帮我划重点。
这门课我一点没学，明天就考，救我。
这是近三年真题，帮我反推考点，做一份复习计划。
```

也可以显式调用：`/exam-prep-coach`

首次使用它会问你四件事（科目/日期、有没有真题或大纲、目标分、教材老师），**一次问完**，然后直接开工。


## 工作流

| 阶段 | 做什么 | 关键判据 |
|---|---|---|
| P0 立项 | 问 4 个问题，建立考试画像 | 知道剩余天数、有无真题、目标分 |
| P1 入库 | 真题 PDF → 逐页页面图 → agent 读图转写成 Markdown | 题号完整、答案齐全、公式可读 |
| P2 反推 | 卷面结构 → 考点 × 年份矩阵 → 期望分 → S/A/B | 每个 S 级考点写出「标准步骤」 |
| P3 编排 | 按剩余天数排日计划 | 每天有可测量的验收 |
| P4 生产 | 讲解 → 习题 → 详解 | 覆盖矩阵 100% |
| P4.5 审查 | 机械扫描 → **盲解复核** → 修 → 重验 | 致命错误 = 0，报告含覆盖清单 |
| P5 自检 | 跑校验脚本 + 过交付闸门 | 无 `[FAIL]` 才交付 |

## 脚本依赖

| 脚本 | 依赖 | 说明 |
|---|---|---|
| 全部 | Python 3 | 无第三方包 |
| `pdf_prepare.py` | macOS + `swiftc`（Xcode Command Line Tools） | 首次运行编译渲染器并缓存到 `~/Library/Caches/exam-prep-coach/`；不抽文本层，转写全靠读图 |
| `check_coverage.py` | 无 | 纯标准库 |
| `audit_scan.py` | 无 | 纯标准库 |

```bash
python3 "$SKILL/scripts/pdf_prepare.py" 试卷.pdf --out markdown/   # → markdown/_pages/*.png
python3 "$SKILL/scripts/audit_scan.py" ai_study/            # P4.5 机械扫描
python3 "$SKILL/scripts/check_coverage.py" ai_study/ --strict
```

## 几个关键设计

- **按「解题动作」分类，不按章节**：同一章里「求导数」和「用导数证不等式」是两个考点，前者套公式，后者要构造。
- **期望分排序**：`出现年数权重 × 平均分值 × 零基础可得性系数`。差 8 倍的考点，先学哪个不用讨论。
- **强制「不复习清单」**：明确写出放弃什么，比列出要学什么更省时间。
- **信号 → 动作**：讲「看到 $u^v$ 就先写成 $e^{v\ln u}$」，不讲这个公式怎么来的。
- **卡点定位**：详解不只给正确答案，还要说「你只写到这一步，说明缺哪个动作」。
- **可被检验**：`check_coverage.py` 会硬性校验题号对应、考点覆盖、S/A 小节有没有留空。
- **审查必须盲解**：生成内容的模型重读自己的输出等于复述，发现不了错。所以审查要求先盖住原文自己算一遍，再对照，并且每条错误都要给"我怎么验的"。讲解讲错、详解答错是两份材料里代价最高的两类错误。

## 边界与免责

- 仓库**不含任何真题、答案或他人笔记**。卷子需要你自己提供。
- 教学方法与模板只是经验总结，不保证分数；请自行判断是否适用于你的课程。
- 转写质量取决于源文件清晰度，公式看不清时 skill 要求标注「（?）」，禁止猜写 LaTeX。
- 本 skill 内容为中文。
