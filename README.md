# exam-prep-coach

**一个让 AI 帮你理工科考前突击的 skill。** 喂它往年真题或模拟卷，它反推考点与重点、排出可执行的复习计划，并产出知识点讲解、分层习题集和逐题详解。

> 目标函数是**分数**，不是理解。默认学生零基础、时间紧。

适用对象：理工科（数学、物理、化学、电路、数据结构、数据库等有计算/推导/操作步骤的科目）期中/期末/考研/资格证等有明确考试日期的场景，尤其是「还有 N 天，这门课我一点没学」的情况。**不适用于纯记忆背诵、语言考试、纯主观论述类科目。**

---

## 它解决什么问题

大多数复习建议是「按教材顺序系统学习」——时间够才成立。时间不够时，真正的问题是：

1. 这张卷子到底考什么？哪些反复出现？
2. 每类题值几分？零基础能拿到几成？
3. 剩下 N 天，先学哪个、明确放弃哪个？
4. 学会了怎么算会了？考场上第一行写什么？

这个 skill 把上面四步做成固定流程，并且强制每个产出都能被检验（题号对得上、考点全覆盖、每天有可测量的验收）。

## 安装

将本目录放到你的 skills 目录（如 `~/.codex/skills/exam-prep-coach`），支持 `SKILL.md` 格式的工具会自动加载。

```bash
git clone https://github.com/Molyuu/exam-prep-coach.git ~/.codex/skills/exam-prep-coach
```

其他读取 `SKILL.md` 的工具（如 Claude Code）放到各自的 skills 目录即可，格式兼容。

装好后无需配置，skill 会出现在会话的 skill 列表里。

## 怎么用

自然语言触发：

```text
我还有 7 天考高数期中，卷子发你，帮我划重点。
这门课我一点没学，明天就考，救我。
这是近三年真题，帮我反推考点，做一份复习计划。
```

也可以显式调用：`/exam-prep-coach`

首次使用它会问你四件事（科目/日期、有没有真题或大纲、目标分、教材老师），**一次问完**，然后直接开工。

## Plan B：不装 skill，直接贴提示词

只备考一门、一次性用，或者工具不支持 skill 时，把下面这段贴在对话开头，再发卷子即可。
能拿到 skill 的大部分效果；代价是没有脚本校验、产出留在聊天里，长对话后需要再贴一次防止跑偏。

```text
你是我的考前突击教练。目标是期望得分最大化，不是学懂。默认：时间紧、我零基础、我要的是考场上写得出来。

【开工】一次问完，最多 4 个问题：科目和考试日期；有没有真题/模拟卷/大纲/老师划的重点；目标分；教材和老师。我已经给了的就别问，缺的写成「假设」直接开工。

【流程】按顺序做，不要跳：
1. 转写：逐页读卷子图片，题号、分值、答案齐全；公式看不清标「（?）」，不许猜。
2. 反推：先列卷面结构（题型 × 分值），再做「考点 × 年份」矩阵。考点按解题动作分，不按章节。
3. 分级：按「出现频率 × 分值 × 零基础可拿分难度」排出 S/A/B，给出 S 级预计覆盖多少分。
4. 不复习清单：先写明放弃什么、为什么，再写要学什么。
5. 日计划：每天 ≤ 3 个任务块，每块 ≤ 60 分钟，每天一条可测量的验收（如「不看笔记 8 分钟做出 25–26 第 15 题」）；最后一天不开新专题。
6. 按天产出：讲解 → 习题 → 详解。先只出 Day 1，我做完再出下一天。

【铁律】
- 可信度标级：A=卷面可见，B=大纲/教材推断，C=听说/经验。没卷子就全部标 B/C，并在开头写「以下为推断」。
- 每个考点四件套：触发信号（看到什么）、标准步骤（第一行写什么）、真题同型例、易错点。
- 讲「看到什么 → 做什么」，不讲概念来历；考证明就把证明当模板背：固定开头、固定取点、固定收尾。
- 每道题标出处「（同型：25–26 解答 15）」，没出处标「自编」。
- 每天 8 道题为基准，上限 12。宁少而闭环。
- 详解不跳步，不写「显然/易得」，每步都能被批改；再加一句卡点定位：「只写到这一步，说明缺哪个动作」。
- 符号第一次出现给读法和用途，不假设我会任何前置知识。
- 仅适用理工科（计算/推导/操作类）；纯记忆、语言、纯论述类科目不适用。
- 交付前自己盲解复核：盖住你写的答案重新算一遍，对不上就修，修完重验那一题。

【写法】短句，一个意思一行；结构、分级、对比一律用表格；数字必须具体（几分、几分钟、第几年第几题）；动词开头。公式行内 $...$、行间 $$...$$，不用 \( \[。禁用：深刻理解、融会贯通、系统掌握、多加练习、举一反三。

【降级】只剩 ≤3 天：只做 S 级 + 一次限时整卷。只剩一晚：一张「今晚 5 小时清单」+ 一页公式/模板纸，反对通宵。明天考且完全没学：只押能拿 50–60 分的模板题，并明说「这是赌」。

每次回复最后只说三件事：结论（能保底多少分）、现在先做哪一步、怎么验收。
```

## 工作流

| 阶段 | 做什么 | 关键判据 |
|---|---|---|
| P0 立项 | 问 4 个问题，建立考试画像 | 知道剩余天数、有无真题、目标分 |
| P1 入库 | 真题 PDF → 逐页页面图 → agent 读图转写成 Markdown | 题号完整、答案齐全、公式可读 |
| P2 反推 | 卷面结构 → 考点 × 年份矩阵 → 期望分 → S/A/B | 每个 S 级考点写出「标准步骤」 |
| P3 编排 | 按剩余天数排日计划 | 每天有可测量的验收 |
| P4 生产 | 讲解 → 习题 → 详解 | 覆盖矩阵 100% |
| P4.5 审查 | 机械扫描 → **盲解复核** → 修 → 重验 | 致命错误 = 0，报告含覆盖清单 |
| P5 自检 | 跑校验脚本 + 过交付闸门 | 无 `[FAIL]` 才交付 |

## 几个关键设计

- **按「解题动作」分类，不按章节**：同一章里「求导数」和「用导数证不等式」是两个考点，前者套公式，后者要构造。
- **期望分排序**：`出现年数权重 × 平均分值 × 零基础可得性系数`。差 8 倍的考点，先学哪个不用讨论。
- **强制「不复习清单」**：明确写出放弃什么，比列出要学什么更省时间。
- **信号 → 动作**：讲「看到 $u^v$ 就先写成 $e^{v\ln u}$」，不讲这个公式怎么来的。
- **卡点定位**：详解不只给正确答案，还要说「你只写到这一步，说明缺哪个动作」。
- **可被检验**：`check_coverage.py` 会硬性校验题号对应、考点覆盖、S/A 小节有没有留空。
- **审查必须盲解**：生成内容的模型重读自己的输出等于复述，发现不了错。所以审查要求先盖住原文自己算一遍，再对照，并且每条错误都要给"我怎么验的"。讲解讲错、详解答错是两份材料里代价最高的两类错误。

## 边界与免责

- 仓库**不含任何真题、答案或他人笔记**。卷子需要你自己提供。
- 教学方法与模板只是经验总结，不保证分数；仅适用于理工科计算/推导/操作类科目，纯记忆、语言、纯论述类不适用；请自行判断是否适用于你的课程。
- 转写质量取决于源文件清晰度，公式看不清时 skill 要求标注「（?）」，禁止猜写 LaTeX。
- 本 skill 内容为中文。
