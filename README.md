# exam-prep-coach

基于往年真题/考试大纲/教材的零基础突击考试规划 SKILL。适用于大学各类理工科考试。

## 安装

直接打开你的 agent（codex, claude code, pi...)

```bash
帮我安装这个 skill https://github.com/Molyuu/exam-prep-coach.git 
```

## 使用

直接对它说，例如：

```text
我还有 7 天考高数期中，卷子发你，帮我划重点。
```

另提供非 skill 纯 prompt 版本 → [PLAN_B.md](PLAN_B.md)
