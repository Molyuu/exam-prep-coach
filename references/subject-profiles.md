# 科目类型画像：拿到陌生真题后怎么选打法

> 配套主 SKILL.md 的 P0 阶段：科目不是计算型时，先读本文判定类型，再决定后续讲解/习题/详解的口径。先做 §0 判定，再跳到对应小节；立场与主文件一致：分数最大化 > 知识完整，不按教材顺序，每个方法必须配同型真题，默认零基础。

## 0. 判定表：两个问题定类型

**Q1 卷面主体是计算还是文字？Q2 答案是背出来的还是推出来的？**

| Q1 卷面主体 | Q2 答案来源 | 归到 | 今天第一个动作 |
|---|---|---|---|
| 计算 / 推导 | 套公式、推步骤 | §1 计算推导型 | 抄 20 条「信号→公式」 |
| 计算 / 操作 | 记得语法、API | §4 代码与数据库型 | 纸手写 10 段最小代码 |
| 动手操作 | 记得步骤顺序 | §5 实验与操作型 | 每实验 1 张四行卡片 |
| 文字 | 背原文、背采分点 | §2 记忆背诵型 | 抄 20 个答题骨架 |
| 文字 | 套语言题型模板 | §3 语言考试型 | 拆 1 套真题算分数 |
| 文字 | 组织观点、拼论据 | §7 主观题与面试型 | 写 5 个万能骨架 |

**判不出来时**：数 1 套真题的分值。计算题 > 60% → §1；文字题里「答案能在教材找到原句」的比例 > 50% → §2；其余看 Q2。

**开卷 / 半开卷 / 一张 A4 不是科目，是载具**：叠加在 §1–§5、§7 任一类上，再读 §6。

## 1. 计算推导型（高数 / 线代 / 概率 / 大物 / 化工 / 电路）

**卷面长相**：给条件求数值、表达式或证明。答案一行，过程按步给分，步骤分常占一半。
**标准题型**：套公式求值｜带参数分类讨论｜化简求通解｜存在性证明｜极值最值应用题。
**零基础先拿的分**：选择填空 20–40 分（套公式 + 特值代入可拿八成）；解答题前 2 道送分题约 20 分；证明题只写「定理条件 + 构造的中间量」拿 2–4 分步骤分。先锁 55–65 分。

**复习动作顺序**：
1. 从真题答案**倒着**抄 20 条「题干信号→公式 / 步骤」，写成一张 A4。
2. 每条配 1 道真题，限时 8 分钟做完；卡住只回看详解断掉的那一步。
3. 只背步骤骨架和公式适用条件，不背推导。
4. 做 1 套整卷，只统计「哪个动作断了」，不统计对错。
5. 每个断点只补 1 个动作，不回读整章。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 一条触发信号 + 编号步骤 + 1 道例题；每个公式加一句「什么时候用」 |
| 习题集 | 按题型分组，每组 3 道：1 道照抄模板 + 2 道变式 |
| 详解 | 每步标分值；卡点写「断在第几步、补哪个动作」 |

**典型陷阱**：① 用定理不验条件（罗尔不验 $f(a)=f(b)$、洛必达不验 $\frac00$）；② 加减项直接做等价替换；③ 只写答案不写中间步，步骤分清零。

## 2. 记忆背诵型（思政 / 近代史 / 法条 / 医学基础）

**卷面长相**：名词解释、简答、论述、材料分析。答案有标准采分点，按点给分，不看文采。
**标准题型**：名词解释（3–5 分一个）｜简答题｜论述 / 材料分析｜判断改错｜填空与选择。
**零基础先拿的分**：选择 + 填空 20–30 分（真题选项重复率高，只背出现过的）；名词解释背 30 个高频词，每个 3 句话 → 15–20 分；简答只写编号要点，一条约 2 分。先锁 50–60 分。

**复习动作顺序**：
1. 把近三年真题整理成「题目 → 答案要点」两列表，答案原文照抄，不做总结。
2. 数每个考点出现次数，≥2 次的写成「题干信号→要点编号」速查页。
3. 名词解释只背「定义句 + 3 个关键词」，不背整段。
4. 每背完 1 个考点，合上原文写关键词，再对照补漏，10 分钟一轮。
5. 论述题背 5 个万能骨架（背景→内涵→意义→联系实际），把 15 个高频考点塞进骨架。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 考点原文 + 采分点分条（1 条 = 1 分）；不写背景故事 |
| 习题集 | 默写填空 + 简答提纲；不要求写完整答案 |
| 详解 | 只给「采分点清单 + 漏了哪条」，不写长段落 |

**典型陷阱**：① 背整段却不背采分点关键词，阅卷找不到按 0 分给；② 简答写成长篇议论文，要点被淹没；③ 只刷选择题题库，简答 50 分没动。

## 3. 语言考试型（四六级 / 考研英语 / 日语 / 雅思）

**卷面长相**：题型固定、时间固定，对错唯一或按 rubric 打分。分高来自题型熟练度，不是词汇量。
**标准题型**：听力（对话 / 篇章）｜阅读（细节 / 主旨 / 词义猜测）｜选词填空｜翻译｜写作（模板 + 话题）。
**零基础先拿的分**：阅读细节题（原文定位，不靠读懂全篇）20–30 分；写作模板 3 套骨架 15 分；翻译固定句式 10 分。先把「阅读 + 写作」锁到 55–60%。

**复习动作顺序**：
1. 拆 1 套真题，按题型列「分值 × 我的正确率」，先攻分值高且靠技巧的（阅读、写作）。
2. 只背 300 个词：真题选项 + 原文里的生词，不背词汇书。
3. 每个题型钉死 1 个动作（细节题：圈题干关键词→回原文定位→比同义替换）。
4. 写作抄 3 套骨架，5 个话题各手写 1 篇，限时 25 分钟。
5. 听力每天 15 分钟精听 1 篇，只练「信号词→答案位置」。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 题型动作清单 + 1 道例题的定位演示（划线在第几行） |
| 习题集 | 按题型分组，单题限时；标「本题该用哪个动作」 |
| 详解 | 给定位句位置 + 错因类型：没定位 / 词不认识 / 没看出同义替换 |

**典型陷阱**：① 背整本单词书，时间压在低频词上；② 阅读靠通读全文，最后两篇做不完；③ 模板背了不手写，考场拼错、字数不够。

## 4. 代码与数据库型（C / Python / 数据结构 / 数据库 / 算法）

**卷面长相**：纸上写代码、读程序写输出、写 SQL。按「跑得对 / 语法点齐」给分，不给部分逻辑分。
**标准题型**：读程序写输出｜补全代码 / 填空｜手写函数或算法｜SQL 查询｜找错改错｜复杂度分析。
**零基础先拿的分**：读程序写输出 20–30 分（手算小样本就能拿）；SQL 单表查询 10–20 分（5 个句式）；手写题只写「骨架 + 注释」拿 30–50% 步骤分。先锁 50–60 分。

**复习动作顺序**：
1. 按「考点→模板代码」整理，每点抄 1 段 10 行以内的最小可运行骨架。
2. 关掉编辑器，纸上默写这 10 段，写完逐行模拟一遍变量。
3. 读程序题固定动作：列变量表，逐行更新，只记变化的值。
4. SQL 只背 5 个句式（`SELECT…WHERE` / `GROUP BY…HAVING` / `JOIN` / 子查询 / `ORDER BY…LIMIT`），每式配 2 道真题。
5. 每个考点手写 1 道真题，对照标准答案只改「我少写的那几行」。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 最小可运行例子 + 逐行注释；标明「哪行不写会崩」 |
| 习题集 | 三档改为：读代码 → 补全 → 独立手写 |
| 详解 | 完整可运行代码 + 每行作用 + 边界用例（空表、$n=0$、重复值） |

**典型陷阱**：① 只看不写，考场手写语法全错（分号、缩进、括号）；② 只测正常用例，边界条件不写；③ SQL 在 `WHERE` 里过滤聚合结果，忘写 `HAVING`。

## 5. 实验与操作型（化学生物实验、操作考试）

**卷面长相**：步骤排序、仪器选择、现象判断、数据处理、误差分析；或现场动手打分。
**标准题型**：步骤排序 / 填空｜仪器识别与选择｜现象描述｜数据处理（平均值、相对误差、作图）｜误差与安全分析｜现场操作。
**零基础先拿的分**：步骤排序题（背 3 条主线流程）10–15 分；现象描述（背「颜色 / 沉淀 / 气体 / 温度」四类词）10 分；数据处理套 3 个公式 10 分。先锁流程分，动手分靠「顺序不错、现象说得出」。

**复习动作顺序**：
1. 每个实验抄 1 张四行卡片：目的 → 步骤 → 现象 → 结论，不超过 1 页。
2. 步骤只背编号顺序 + 每步一个动词（取样→溶解→加热→过滤→称量）。
3. 现象背固定句式：「溶液由 X 色变为 Y 色，并有 Z 生成」。
4. 数据处理只背 3 个公式 + 1 条有效数字规则（乘除看最少位数）。
5. 考前大声口述一遍全流程，卡住的地方就是考场卡住的地方。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 四行卡片 + 逐句操作描述（像旁白）；原理只留一句 |
| 习题集 | 步骤排序 + 现象填空 + 数据表填算 |
| 详解 | 标准步骤顺序 + 每步一句「为什么」+ 常见扣分点 |

**典型陷阱**：① 背原理不背步骤顺序，顺序错整题扣完；② 有效数字位数乱写；③ 安全与废液处理漏写（有卷子直接扣分）。

## 6. 开卷 / 半开卷 / 带一张 A4

**卷面长相**：题量大、允许带资料。真正的难点是翻书慢，不是知识量。
**标准题型**：材料分析｜可查公式的计算题｜可抄要点的简答论述｜判断题。
**零基础先拿的分**：选择题（可查）全拿；计算题只练「查哪个公式」；简答抄要点但重排编号。先锁「每题 3 分钟定位」的速度分。

**复习动作顺序**：
1. 做 1 张 A4（正反）索引表：左列题干关键词，右列页码 / 编号 + 公式。只写索引，不抄正文。
2. 用真题做定位训练：单题 3 分钟内找到并抄完，连做 10 题。
3. 给 15 个高频考点贴便利贴标签，考场直接翻。
4. 预先写好 5 个开头段 + 3 个结论句，考场只做拼装。
5. 模拟 1 次整卷，统计翻书耗时；超过总时长 25% 就砍掉一半索引条目。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 索引式：考点 → 公式编号 / 页码，不写推导 |
| 习题集 | 每题加「3 分钟定位」限时，答案允许抄 |
| 详解 | 标「这段在书上哪一页」+ 抄写时该怎么改写 |

**典型陷阱**：① 把整本书抄进 A4，字太密反而找不到；② 只做表不训练，考场第一次翻就慌；③ 以为开卷不用背，每题多花 5 分钟。

## 7. 主观题与面试型（专业课论述、复试）

**卷面长相**：给材料或问题，写论点 + 论证；按 rubric 给分（观点、论据、结构、语言）。
**标准题型**：论述 / 材料分析｜案例分析｜观点评价｜方案设计｜口述问答与追问。
**零基础先拿的分**：结构分（写清总—分—总就有基础分）；论据分（每条论点配 1 个案例或数据）；术语分（用对 5 个专业词替掉大白话）。先锁 60% 的结构与术语分。

**复习动作顺序**：
1. 从真题答案或评分标准抄 10 个答题骨架（如「提问题→析原因→给对策→作评价」）。
2. 每骨架配 1 道真题，只写提纲，限时 3 分钟，不写全文。
3. 准备 10 个万能论据：1 个案例 + 1 组数据 + 1 句原文，每条压到 2 句话。
4. 口述题准备 60 秒版本（结论 + 2 条理由 + 1 个例子），录音回听 1 遍。
5. 做 1 次模拟问答，卡住的题标「必补」，其余不补。

| 交付物 | 这类科目要改成 |
|---|---|
| 知识点讲解 | 骨架 + 1 段范例（1 段足够，不要 3 段） |
| 习题集 | 只写提纲和关键词，不写全文 |
| 详解 | 给「采分点 + 加分句」，指出漏掉的术语 |

**典型陷阱**：① 写满一整页却不分点，阅卷找不到关键词；② 只有观点没有论据，论据分全丢；③ 面试背稿，一追问就断——背骨架，不背稿。

## 8. 跨学科通用铁律

| # | 铁律 | 落地动作 |
|---|---|---|
| 1 | 真题出现 ≥2 次的题型必须做成模板 | 每题写成「信号→步骤」，压缩到 1 页 |
| 2 | 0 基础先放弃低频难题 | 每科写「不复习清单」≥3 条并说明理由 |
| 3 | 每科一张「信号→动作」速查表 | A4 正反，≤30 条，考前只背这张 |
| 4 | 一个方法必须配 1 道同型真题 | 没配到题的讲解直接删，不要留 |
| 5 | 第一天先用 30 分钟只看 1 套整卷的题型与分值分布，不做题 | 先算清这张卷子值多少钱；限时整卷排到 S 级学完之后再做 |
| 6 | 计划总时长 ≤ 有效学习小时（剩余天数 × 3 小时 × 0.85），验收写成动作 | 剩 7 天只排 6 天；验收不是「学完」，是「合上书 8 分钟写出第 15 题」 |

**一句话**：先判类型，再只学这个类型里「出现频率 × 分值 × 零基础可拿」最高的那一块。
