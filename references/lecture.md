# P4-A 零基础知识点讲解的写法

读者设定：**上课没听、教材看不懂、看到符号就慌**。他不需要懂，他需要"照着做能出答案"。
判断标准只有一条：**学生读完这一节，能不能立刻动手做出一道真题？**

## 1. 每节固定六段

不许自创结构，六段都齐才算写完：

| 段 | 内容 | 字数上限 |
|---|---|---|
| ① 人话定义 | 一句话说清它是什么，不用术语 | 2 行 |
| ② 什么时候用 | 触发信号清单：题干出现什么就想到它 | 3–5 条 |
| ③ 标准步骤 | 编号步骤，每步一个动作，可背 | 3–6 步 |
| ④ 例题 | 真题同型，完整解，标注出处 | 1–2 题 |
| ⑤ 易错 | 最多 3 条，写"你会写成什么"和"正确的写法" | ≤ 3 条 |
| ⑥ 一句话记住 / 验收 | 口诀或可测标准 | 1 行 |

## 2. 正例（照这个写）

```markdown
## 1.2 等价无穷小（核心武器）

**是什么**：$x\to0$ 时，两个都趋于 0 的量如果比值趋于 1，就可以在乘除里互换。

**什么时候用**
- 极限式子里出现 $\sin$、$\tan$、$\ln(1+x)$、$e^x-1$、$1-\cos x$ 且 $x\to0$；
- 整个式子能整理成**乘除**形式；
- 出现在**加减**里 → 先通分/提公因子化成乘除，否则改上泰勒。

**标准步骤**
1. 确认 $x\to0$（不是 0 就先换元：$t=x-x_0$）；
2. 把式子化成纯乘除；
3. 逐个因子替换；
4. 算比值。

**例**（同型：25–26 选择 2）求 $\lim\limits_{x\to0}\dfrac{\sin 3x}{\ln(1+2x)}$。
解：$x\to0$ 时 $\sin3x\sim3x$，$\ln(1+2x)\sim2x$，代入得 $\dfrac{3x}{2x}=\dfrac32$。

**易错**
- ❌ $\dfrac{\tan x-\sin x}{x^3}$ 直接换成 $\dfrac{x-x}{x^3}=0$；✅ 先提公因子 $\dfrac{\sin x(1-\cos x)}{x^3\cos x}$ 再换，答案 $\tfrac12$。
- ❌ 忘了"比值必须趋于 1"，把 $\sqrt{1+x}-1\sim x$ 当成等价（实际 $\sim\tfrac x2$）。

**记住**：乘除随便换，加减先化积。
```

## 3. 反例（这样写等于没写）

```markdown
## 1.2 等价无穷小

等价无穷小是极限计算中的重要工具，其理论基础来自泰勒展开的一阶近似。
理解其本质有助于我们在复杂问题中灵活运用。常见的等价无穷小包括……
```

问题：没有"什么时候用"、没有步骤、没有例题、没有易错，学生读完仍然不会做题。**判不合格，重写。**

## 4. 抽象概念 → 最小可操作定义

零基础学生卡住，几乎都是因为定义里套定义。转换公式：

| 原样 | 改成 |
|---|---|
| "$f$ 在 $x_0$ 处连续" | "左极限 = 右极限 = 函数值，三样相等（做题就查这三样）" |
| "$\xi$ 满足中值定理条件" | "在 $(a,b)$ 里存在一个点，公式里那个 $\xi$ 就是它，不用求出来" |
| "收敛" | "$n$ 变大时数列越来越靠近某个固定数；做题先证它不跑远、不变头" |
| "秩为 2"（线代） | "化简后非零行有 2 行" |

规则：**定义里每出现一个术语，就要么解释，要么给一个可检查的操作。**

## 5. 信号 → 动作速查表

每个科目、每一天的内容最后都要有一张这个表，它是考场上的命脉：

| 题干出现 | 立刻想到 | 第一个动作 |
|---|---|---|
| $u^v$，$u\to1$ | $1^\infty$ 型 | 写成 $e^{v\ln u}$ |
| $e^{1/x}$、$\arctan\frac1x$、$\lvert x\rvert$ | 左右极限可能不同 | 分左右算 |
| 参数方程求二阶导 | 忘了再除一次 | 先写 $\frac{dy}{dx}=\frac{y'_t}{x'_t}$ |
| 求 $f^{(n)}(0)$，题里有展开式 | 读系数 | $f^{(n)}(0)=n!\,a_n$ |
| 证"存在 $\xi$ 使…"且要构造 | 辅助函数 | 先看结论能不能整理成 $F'(\xi)=0$ |

## 6. 例题规范

- 例题必须是**真题同型**，标注 `（同型：25–26 解答 15）`；没有真题就用"自编"，并说明是自编。
- 例题讲解要**完整**：条件 → 第一步写什么 → 为什么这一步 → 结果。零基础学生最缺的是"第一步写什么"。
- 讲解顺序：先给"思路一句话"，再给完整步骤。不要让学生跟着推导走丢。
- 每节最多 2 道例题。例题多了学生会只看不做。

## 7. 密度与节奏

| 项 | 限制 |
|---|---|
| 每天节数 | 2–4 节 |
| 每节行数 | ≤ 60 行（超出说明掺了无关内容） |
| 每个公式第一次出现 | 必须有"什么时候用" |
| 每节公式数 | ≤ 8 个；多了拆节 |
| 每段长度 | ≤ 3 行 |

## 8. 三条禁忌

1. **不写来历**。不写"这个定理是柯西在 1823 年…"、"由泰勒展开可得…"。除非考点要求推导。
2. **不写"显然""易得""不难看出"**。零基础眼里没有显然。
3. **不一次给全部变体**。先把最常考的那一种写死，变体放到习题集的"挑战"档。

## 9. 语气句式库（可直接套用）

- 「看到 X，就先写 Y。」（建立条件反射）
- 「这一步必须在卷子上写出来，不能只在心里算。」（拿过程分）
- 「如果卡在这里，说明你还没背下 X。」（卡点定位）
- 「先不管为什么，照这个顺序写三行就能得步骤分。」（降低启动门槛）
- 「这个只考一种情况，记住就行。」（消除焦虑）
- 「考场上如果 2 分钟没思路，跳过。」（止损）

## 10. 交付前自问三句

1. 一个只学过四则运算的人，能照着这一节做出第一道例题吗？
2. 这一节有没有告诉他"什么时候用"？
3. 删掉三分之一，会不会更好？（会 → 删）

## 11. 文件级约定

- 一个文件放 Day1–N，按天用 `# 第 N 天：<主题>` 分节，节内 `## N.1`、`N.2` 编号。
- 文件开头写配套关系和使用方法（先读讲解 → 再做当天真题 → 对照详解）。
- 结尾写「使用建议」：每天 45–60 分钟，读完立刻动笔。
