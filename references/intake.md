# P0 立项：信息采集与考试画像

目标：**5 分钟内**搞清楚这张卷子值多少分、还剩多少时间，然后立刻开工。不做长问卷。

## 1. 四个问题（一次问完）

按这个模板发出去，不要拆成多轮：

```text
开工前只问四件事，你一次回我就行：
1) 考哪门、哪天考、考试时长多少？
2) 有往年真题 / 模拟卷 / 大纲 / 老师划的重点吗？有就发我（PDF、图片、聊天截图都行）。用的哪本教材、老师有没有说过"必考/不考"？
3) 目标分数？没有目标我就按"过线以上一点"来排。
4) 从现在到考试，每天实际能拿出几小时？（说实话，按做得到的说）
```

## 2. 缺信息时的默认假设

| 缺什么 | 默认假设 | 写在哪 |
|---|---|---|
| 目标分 | 过线以上 10–15 分 | 路线文件开头画像行 |
| 剩余天数 | 按 7 天排，并额外给"3 天版"和"一晚版" | `references/plan.md` 档位 |
| 每天可投入小时 | 3 小时；学生报 > 6 小时按 6 排（报的数通常偏乐观） | 画像行 + 路线文件「假设」 |
| 真题 | 走降级模式，全部结论标 `B`/`C` | §5 |
| 老师/教材 | 用通用符号；遇到符号不确定就两种都写一遍再选一个 | 讲解文件脚注 |
| 学生基础 | 零基础：不假设会任何前置技能 | 全部产出 |

**不要因为缺信息就不产出**。把假设亮出来，比卡在提问上更有用——学生明天就考。

## 3. 画像行（每个产物第一行都要有）

```markdown
> 适用：<科目> <考试名>｜剩余 <N> 天｜每天 <H> 小时｜目标 <分数>｜基础：<零基础 / 薄弱 / 中等>
```

这句话有三个作用：提醒模型别写超纲内容、提醒学生这份材料有保质期、让不同文件之间口径一致。

## 4. 顺便要采集的四条硬信息

这几条直接决定后面怎么排，比"目标分"更影响得分：

1. **卷面结构**：几道选择、几道填空、几道大题、各多少分、多少时间。→ 决定考场时间分配。
2. **允许带什么**：闭卷 / 开卷 / 一张 A4 纸 / 计算器 / 公式表。→ 决定要不要做"作弊纸"（合法的）。
3. **给分方式**：大题是按步骤给分还是看结果、有没有过程分。→ 决定详解要不要写"保底步骤"。
4. **有没有"必考"声明**：老师说的"这章一定考"权重最高，但**标 `B`**（来源：老师原话）。只有它在卷面上真的反复出现，才升 `A`。

## 5. 有真题 → A 模式；没真题 → 降级模式

| | A 模式（有卷子） | 降级模式（没卷子） |
|---|---|---|
| 依据 | 卷面统计 | 大纲 + 教材目录 + 课后题 + 老师原话 + 学长回忆 |
| 可信度 | 主体标 `A` | 全部标 `B` 或 `C`，并在开头写一句"以下为推断" |
| 第一步 | 逐题打标签 | 先按大纲列章节，再按"老师讲过两遍"排序 |
| 风险 | 往年考点今年可能变 | 可能整段押空，必须留保底章节 |
| 做法 | 见 `references/reverse-engineer.md` | 见该文件末尾"无真题降级算法" |

降级模式不是低质量模式。没卷子时，**优先级顺序**改为：老师原话 > 大纲标注"掌握"的条目 > 教材课后题重复出现的题型 > 学长回忆。

## 6. 立项完成判据

- [ ] 画像行写得出来（科目、日期、剩余天数、每天小时、目标分、基础）
- [ ] 知道卷面结构和给分规则
- [ ] 决定了走 A 模式还是降级模式
- [ ] 知道允许带什么进场（决定要不要产出速查纸）

四项齐了就直接进 P1，不要继续问。
