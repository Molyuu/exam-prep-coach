# 交付、入库与维护

## 1. 目录结构

沿用工作区已有约定。**已有 `markdown/` + `ai_study/` 就照旧用，绝不另起炉灶**——学生的笔记软件、双向链接都在那里。

```
<工作区>/
├── AGENTS.md                       # 本工作区的写作约定（必须生成）
├── <原始卷子>.pdf / .docx
├── markdown/                       # 转写后的卷子
│   ├── <卷名>.md
│   └── _pages/<卷名>-p01.png       # 页面图，转写的唯一依据
└── ai_study/
    ├── 复习路线_<范围>.md
    ├── 知识点讲解_Day1-<N>.md
    ├── 习题集_Day1-<N>.md
    ├── 习题集_详解.md
    └── 错题表.md
```

## 2. 命名规则

| 文件 | 命名 | 例 |
|---|---|---|
| 路线 | `复习路线_<范围>.md` | `复习路线_近三年真题版.md` |
| 讲解 | `知识点讲解_Day1-<N>.md` | `知识点讲解_Day1-5.md` |
| 习题 | `习题集_Day1-<N>.md` | `习题集_Day1-5.md` |
| 详解 | `习题集_详解.md` | 固定 |
| 错题 | `错题表.md` | 固定 |
| 转写 | 与 PDF 同名 | `25-26高数I期中试卷参考答案.md` |

规则：**文件名带范围或天数**，方便学生一眼知道覆盖到哪天；不要用 `未命名`、`最终版`、`v2`。

`N` = 讲解覆盖到的**最后一天**，可以和计划总天数不同：例如 7 天计划只出 Day1–5 的讲解与习题，Day6 是限时整卷、Day7 只做复盘，那两天不需要新内容，文件名就叫 `Day1-5`。

## 3. 写作约定（生成 AGENTS.md）

每个新工作区第一件事：写 `AGENTS.md`，把公式语法和产出位置钉死，后面所有文件自动遵守。

```markdown
# AGENTS.md

## Markdown / LaTeX 语法约定

本目录是 Obsidian vault。生成或修改 `.md` 文件时：

- 行内公式用 `$...$`（禁止 `\(...\)`）；
- 行间公式用 `$$...$$`（禁止 `\[...\]`）；
- `$$` 块独立成行，前后留空行；
- 不要在公式块前加 `+`、`-` 列表符号。

## 产出约定
- 真题转写 → `markdown/`
- 复习材料 → `ai_study/`
```

模板见 `templates/AGENTS.md`。

## 4. P1 入库：卷子转文本

**一律读图转写，不抽 PDF 文本层。** 文本层实测不可信：分式、上下标散架，`(cid:xx)` 乱码会把字符数抬高到"看起来很完整"，Symbol 字体还会把 $\alpha$ 解成 `a`。电子版、扫描件都走同一条路。

```bash
export SKILL=<装载路径>     # 以 skill 装载时的 Base directory 为准，如 ~/.codex/skills/exam-prep-coach
python3 "$SKILL/scripts/pdf_prepare.py" *.pdf --out markdown/     # 可加 --dpi 200 看清小字
```

脚本把每页渲染到 `markdown/_pages/<stem>-pNN.png` 并打印路径与转写目标 `markdown/<stem>.md`（重跑会先清掉同名旧页图）。
手机拍照/截图本来就是图片，直接读图，不用跑脚本。Word 先导出 PDF。

然后**逐页读图转写**到 `markdown/<stem>.md`，要求：

1. 题号、分值、括号、下划线全部保留；
2. 数学式转成 LaTeX，不确定的写成纯文本并用 `（?）` 标注，**不许猜**；
3. 图文题保留"图略 + 文字描述"；
4. 每份卷子先转 1 页 → 自己读一遍 → 确认可读再批量转。

### 转写完成判据

- [ ] 题号连续，无缺题（对照 PDF 页数估题数）
- [ ] 分值与卷面一致，总分能加满
- [ ] 答案卷与试卷题号对齐
- [ ] 抽查 3 道题的公式能在 Obsidian 里正常渲染
- [ ] `markdown/` 下每份文件非空（`check_coverage.py` 会查）

## 5. 增量维护：又来了一年卷子

不要重做全部，按这个顺序增量更新：

1. 转写新卷子 → `markdown/`；
2. 在考点 × 年份矩阵里**加一列**；
3. 重新算期望分，看有没有考点升级/降级；
4. 只有分级变了才动计划：把新升级的写成 S/A 级，新增的降级考点移入"不复习清单"；
5. 新增题补进习题集（标 `同型：新卷题号`），详解补对应条目；
6. 跑 `python3 "$SKILL/scripts/check_coverage.py" .` 确认没有孤儿题。

**不改的东西**：讲解文件的编号体系、已有的验收标准。改编号会让学生对不上旧笔记。

## 6. 交付时对用户说什么

只回三段，不要罗列文件清单（文件他看得到）：

```text
1) 结论：这套卷子约 <X> 分的题集中在 <N> 个模板上，保底能拿 <Y> 分。
2) 现在做：打开 <复习路线文件>，照「今天立刻执行的 45 分钟」做第一块。
3) 验收：<可测量标准，例：8 分钟内独立做出 25–26 第 15 题>。
```

三句话的次序不能换：先给结论（安心），再给动作（启动），最后给标准（可自检）。

## 7. 维护陷阱

| 陷阱 | 后果 | 处理 |
|---|---|---|
| 在工作区根目录乱丢临时文件 | Obsidian 里一片红 | 临时文件写 `/tmp` |
| 改了 `ai_study/` 已有文件的编号 | 学生笔记对不上 | 只增不改编号 |
| 用 `\(` `\[` 写公式 | Obsidian 不渲染，满屏源码 | 见 §3 |
| 中文文件名带空格/斜杠 | 命令和链接全挂 | 用中文全角括号，不用空格 |
| 把答案直接写进习题集 | 学生失去练习价值 | 答案只在详解里 |
| 一次性生成 5 天全部内容 | 学生不看，你也改不动 | 先出路线 + Day1 三件套，跑通再批量 |
