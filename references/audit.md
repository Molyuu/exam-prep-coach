# P4.5 内容审查：证明讲解和详解是对的

讲解写错，学生会学错，而且学得越认真错得越牢；详解写错，学生会把做对的改错。这两类错误**重读发现不了**：生成者重读时是在复述自己的推导，不是在重新计算。所以审查只认一件事：**判定建立在重新计算上，不建立在阅读印象上。**

## 三条规则

1. **盲解优先**：先盖住原文，自己算出结果写下来，再对照。不许边读边判「这样写对」。
2. **每条错误带可复算的证据**：原文引用 + 错在哪 + 正确写法 + 验证手段（回代 / 特殊值 / 定理条件 / 反例）。给不出验证的只能标「可疑」。
3. **没找到错也要写覆盖清单**：查了哪几节、哪几题、用什么方法。空白报告 = 没审。

## 谁来审

| 方式 | 做法 | 强度 |
|---|---|---|
| 独立上下文（推荐） | 派 subagent / 新会话，只给待审文件 + 原始卷子 + 本文件的分级标准，不给生成时的推理，也不提示「哪里可能有问题」 | 强 |
| 同上下文盲解 | 先写自己的解，再看原文；必须重算，不许引用上文步骤 | 中 |
| 再读一遍 | — | **不算审查** |

## 讲解：12 类检查

| # | 类型 | 怎么查 |
|---|---|---|
| 1 | 定理条件漏（洛必达不验 $\frac00$、罗尔不验三点） | 抄出定理前置条件，逐条对原文 |
| 2 | 公式抄错（泰勒系数、等价阶数、导数公式） | 代特殊值，如 $x=0.1$ 数值比较两边 |
| 3 | 等价 / 同阶混淆（$\sqrt{1+x}-1\sim x$） | 算比值是否趋于 1 |
| 4 | 充分必要方向反了 | 找反例：$\lvert x\rvert$ 连续不可导 |
| 5 | 过度推广（「所有函数都…」） | 举反例，或查条件能否支撑全称 |
| 6 | 适用范围错（$x<0$ 用 $\ln x$、开闭区间） | 逐个标定义域 / 区间 |
| 7 | 不可逆变形（平方、约掉可能为 0 的因子） | 查增根 / 漏根 |
| 8 | 记号错（$dy$ 与 $\Delta y$、$f'(x_0)$ 与 $f'(x)$） | 每个符号问一句：它是数还是函数 |
| 9 | 例题与所讲方法不符 | 例题步骤能否一一对上标准步骤 |
| 10 | 「易错点」本身写错 | 把每条易错当独立命题验一遍 |
| 11 | 数值算错 | 独立复算 |
| 12 | 引用不实（标「同型」其实是原题，或根本不同型） | 打开原卷对一遍 |

第 10 类最容易漏，错了会让学生把对的改错。

## 详解：10 类检查

| # | 类型 | 怎么查 |
|---|---|---|
| 1 | 最终答案错 | 独立算，只比答案 |
| 2 | 中间步骤错或漏项，但答案恰好对 | 逐步重算；数公式项数（$n$ 阶泰勒 = 多项式各项 + 余项），对照后文「某项抵消」到底用了哪几项 |
| 3 | 漏解 | 开方丢 $\pm$、分类漏支、分段点没算 |
| 4 | 未证明的断言 | 搜「显然 / 易得 / 注意到」，逐个补证 |
| 5 | 循环论证 | 是否用结论推结论 |
| 6 | 条件未验证 | 中值定理、洛必达、分母非零；归纳法只证了一个方向 |
| 7 | 答非所问 | 问 $y''$ 答 $y'$ |
| 8 | 单位 / 符号 | 物理查量纲，数学查正负号 |
| 9 | 与讲解方法冲突 | 同一考点两处模板不同 |
| 10 | 答案不可判（「约为」「基本是」） | 考场能不能照抄 |

## 真实案例：答案对，讲解错

- 讲解写「奇函数的偶数阶导数是偶函数」——错，应为奇函数（反例 $x^3$：$f''=6x$ 是奇函数）。但它紧跟的推论「$f$ 奇 $\Rightarrow f^{(2k)}(0)=0$」是对的，顺着结论验证会一路通过。只有把那句话当独立命题找反例才抓得到。
- 详解在 $x_0=\tfrac12$ 处展开泰勒公式，漏了 $f'(\tfrac12)(0-\tfrac12)$ 这一项，后文却写「$f'(\tfrac12)$ 项抵消」。结论仍成立，所以只对答案永远发现不了。同一个错误还被复述进了复习路线，三处同错。

教训：**答案全对不等于过程没问题**；错误会在文件之间复制，所以审到一个错，要按结论关键词在全部产物里搜一遍。

## 数值验证手法

| 手法 | 适用 |
|---|---|
| 回代原式 | 方程、隐函数、微分方程 |
| 特殊值 | 恒等式、极限、不等式 |
| 求导验证 | 不定积分 |
| 端点与临界点 | 单调性、最值 |
| 取 $n=1,2,3$ 手算 | 数列、组合、概率 |
| 反例搜索：$\lvert x\rvert$、$x^2\sin\frac1x$、分段函数 | 全称命题、充分性 |

## 流程

顺序：**先讲解，再详解，最后复习路线**（详解的方法来自讲解，路线会复述讲解里的结论）。

1. 按天切块，审完修完再进下一天；
2. 讲解：例题盲解 → 对照 → 过 12 类 → 修；
3. 详解：不看讲解做题 → 对答案 → 过 10 类 → 修；
4. 先保 S/A 级，B 级可以标「未审」；时间不够至少审完 S 级讲解 + 对应详解；
5. 每处修改都**重跑那一题的盲解**——改错比不改更常见。

审已有内容（工作区里已经有 `ai_study/`）：没有考点清单就先粗排一份 S/A，从 S 级往下审；**先出报告再改文件**。

## 分级

| 级别 | 判据 | 处理 |
|---|---|---|
| **致命** | 答案错 / 概念错 / 条件漏，学生会学错 | 必须改，改完重审 |
| **严重** | 推理不成立或漏情况，但答案恰好对 | 必须改 |
| **轻** | 表述、记号、排版 | 记录，可选修 |
| **撤销** | 审查者自己算错 | 明确撤销并写原因 |

误报比漏报更糟：报错一条其实没错，学生会对整份材料失去信任。

```markdown
## 结论
致命 <0>｜严重 <X>（已修 <X>）｜轻 <X>｜撤销 <X>

## 问题
| # | 位置 | 原文引用 | 类型 | 级别 | 正确写法 | 验证手段 | 状态 |
|---|---|---|---|---|---|---|---|
| 1 | 习题集_详解.md Day 3 #4 | 「$y''=-1$」 | 详解 1 最终答案错 | 致命 | $y''=-\frac18$ | 重算 + 代 $t=0$ | 已修，重验通过 |

## 覆盖清单（没有这一节视为未审）
| 范围 | 已审内容 | 方法 | 覆盖度 |

<逐条抄 SKILL.md §6 并打勾>
```

最终给用户的话里加一句审查结论，格式见 `write.md` §7。

## 出现这些想法就停

「我读过一遍，没问题」→ 你没算。「这一步是我推的，肯定对」→ 生成者带着同样的误解。「答案看着合理」→ 错误答案通常也看着合理。「报告最后再补」→ 最后一定不补。
