# P4.5 内容审查：证明讲解和解答是对的

## 为什么必须单独设一道工序

两个失效点代价最高：

- **讲解写错** → 学生学错，而且学得越认真错得越牢；
- **详解写错** → 学生把做对的改错，比不会更糟。

而这两类错误**恰恰不会被"再读一遍"发现**。原因是：内容由同一个模型生成，它重读时是在复述自己的推导路径，而不是重新计算。看起来通顺、符号眼熟，就判"没问题"。

所以审查的设计目标只有一个：**让判定建立在重新计算上，而不是建立在阅读印象上。**

## 三条铁律

1. **盲解优先**：先盖住原文，自己独立算出结果并写下来，再对照。不许边读边判"这样写对"。
2. **每条错误必须带可复算的证据**：原文引用 + 错在哪 + 正确写法 + 验证手段（回代/特殊值/定理条件/反例）。给不出验证的，只能标"可疑"，不能标"错误"。
3. **没找到错也要交覆盖清单**：查了哪几节、哪几题、用了什么方法。空白报告 = 没审。

## 审查者必须独立

最有效的做法是**换一个上下文**审：

| 方式 | 做法 | 强度 |
|---|---|---|
| 独立上下文（推荐） | 派一个 subagent / 新会话，只给它「待审文件 + 原始卷子」，不给生成时的推理过程 | 强：没有自我确认偏差 |
| 同上下文盲解 | 同会话审，但强制：先写自己的解，再看原文；且必须**重算**，不许引用上文写过的步骤 | 中：仍有锚定风险 |
| 再读一遍 | —— | **不算审查，禁止当作已完成** |

给独立审查者的任务书要包含三样：待审文件、原始真题（核对"同型"引用）、错误分级标准。**不要**告诉它"这里可能有问题"的位置，否则它只会确认你的怀疑。

## 一、讲解的知识性错误：12 类检查清单

逐节过，每类给一句"怎么查"。

| # | 类型 | 长什么样 | 怎么查 |
|---|---|---|---|
| 1 | 定理条件漏 | 直接写「用洛必达」不验 $\frac00$；罗尔不验三点 | 逐条抄出定理前置条件，对着原文数有没有写 |
| 2 | 公式抄错 | 泰勒系数、等价无穷小的阶、导数/积分公式错项 | 代特殊值算（如 $x=0.1$ 数值比较两边） |
| 3 | 等价 / 同阶 / 高阶混淆 | 把 $\sqrt{1+x}-1\sim x$ 当等价（实为 $\tfrac x2$） | 等价必须"比值 → 1"，算一遍比值 |
| 4 | 充分必要方向反了 | 「连续必可导」「可导不能推连续」 | 找反例：$\lvert x\rvert$ 连续不可导 |
| 5 | 漏反例 / 过度推广 | 「所有函数都可以…」「一定存在」 | 举一个反例，或检查条件是否支撑全称 |
| 6 | 适用范围错 | 在 $x<0$ 用 $\ln x$；$\arctan$ 无界；开区间当闭区间 | 逐个条件标定义域/区间 |
| 7 | 不可逆变形 | 两边平方、乘除未知符号、约掉可能为 0 的因子 | 检查是否有增根/漏根 |
| 8 | 记号错 | $dy$ 与 $\Delta y$、$f'(x_0)$ 与 $f'(x)$、偏导与全导 | 每个符号读一遍：它表示一个数还是一个函数 |
| 9 | 例题与所讲方法不符 | 讲了等价无穷小，例题其实用洛必达 | 例题解法步骤能否一一对上"标准步骤" |
| 10 | "易错点"本身写错 | 把正确写法标成"❌" | 这条最容易漏：把每条易错点当成独立命题验一遍 |
| 11 | 数值算错 | 例题中间结果、代入的数值 | 重算，至少一次独立复算 |
| 12 | 引用不实 | 标"同型"其实是原题；或与那道题根本不同型 | 打开原卷对一遍：原题要直接标原题编号，改编题才标"同型" |

第 10 条要特别强调：**讲"易错"的地方本身最常错**，而且错了会让学生把对的改错。

### 真实案例：一句话说反，结论却是对的

某次实际审查在一份高数讲解里抓到（原文）：

> 求导一次，奇偶性翻转一次：偶函数的奇数阶导数是奇函数，**奇函数的偶数阶导数（含零阶，即函数本身）是偶函数**。

第二半句是错的：奇函数求一次导变偶、再求一次导变奇，所以奇函数的**偶数阶导数是奇函数**，奇数阶导数才是偶函数。反例 $f(x)=x^3$：$f'(-1)=f'(1)=3$（偶），$f''(-1)=-6$、$f''(1)=6$（奇，不是偶）。

关键在于：**它后面紧跟的两条推论是对的**（$f$ 奇 $\Rightarrow$ $f^{(2k)}(0)=0$，这恰恰要求 $f^{(2k)}$ 是奇函数才能推出）。这种"结论对、讲解错"最难被通读发现——读者顺着结论验证会一路通过。只有把那句陈述当成**独立命题**去验反例，才抓得到。

同一批审查还发现：详解用归纳法证"数列有界"时只证了上界 $x_n<2$，下界 $x_n>0$ 没证，而后续单调性的等价变形（开方）依赖 $x_n>0$。最终答案正确，所以容易被判"没问题"——这属于第 6 类（条件未验证），归"严重"。

### 真实案例二：漏掉一次项，答案却还是对的

另一条来自同一次审查（原文）：

> 在 $x_0=\tfrac12$ 处用带拉格朗日余项的泰勒公式（$n=1$）。代入 $x=0$：$0=f(0)=1+\frac{f''(\xi_1)}{2}\cdot\frac14$

错在**漏掉了 $-\frac{f'(1/2)}{2}$ 这一项**——$n=1$ 的展开在 $x_0=\tfrac12$ 处应为
$f(0)=f(\tfrac12)+f'(\tfrac12)(0-\tfrac12)+\frac{f''(\xi_1)}{2}(0-\tfrac12)^2$。
更明显的破绽是：同一段后文写着"两式相加，$f'(\tfrac12)$ 项抵消"——**后文用了这一项，前文却没有它**。

正确写法两式相加得 $f''(\xi_1)+f''(\xi_2)=-16$，结论（至少一个 $\le-8$）依然成立，所以只对答案永远发现不了。

同一类错误还在别处：有一份讲解说"取 $n=1$ 的泰勒公式，移项就是拉格朗日中值定理"——对应的是 $n=0$，$n=1$ 带 $f''$ 余项，怎么移项也得不到 $f'$ 的式子。**这句话在复习路线里被复述了两遍**，三处同错。

这两个例子说明同一件事：**"答案全对"不等于"讲解和过程没问题"**，而学生会照着讲解和过程去学；**错误还会在文件之间复制**，只查一个文件抓不全。

## 二、详解的解答错误：10 类检查清单

| # | 类型 | 怎么查 |
|---|---|---|
| 1 | 最终答案错 | 独立算，不看过程，只比答案 |
| 2 | 中间步骤错（但答案对） | 逐步重算，抓"恰好抵消" |
| 3 | 漏解 | 开方丢 $\pm$、分类讨论漏支、分段点没算、多解只写一个 |
| 4 | 未证明的断言 | 搜"显然/易得/注意到"，逐个补证或判不合格 |
| 5 | 循环论证 | 检查是否用结论本身推结论 |
| 6 | 条件未验证 | 中值定理三点、洛必达、级数收敛、分母非零；归纳法只证一个方向（证了上界没证下界） |
| 7 | 答非所问 | 问 $y''$ 答 $y'$；问"是否存在"只给构造 |
| 8 | 单位 / 量纲 / 符号约定 | 物理类必查；数学查正负号 |
| 9 | 与讲解的方法冲突 | 同一考点两处给不同模板 → 学生无所适从 |
| 10 | 答案不可判 | "约为"、"基本是"、范围模糊，考场无法写 |
| 11 | 公式漏项 | 泰勒/分部/换元漏掉一次项或系数，且与后文"某某项抵消"的说法自相矛盾——把公式的项数数一遍（$n$ 阶展开 = 多项式各项 + 余项），再对照后文到底用了哪几项 |

## 三、先跑机械检查，再人工

机械能查的不要用眼睛查：

```bash
python3 "$SKILL/scripts/audit_scan.py" <工作区>/ai_study
```


**扫描器也会误报**：围栏代码块与行内代码已屏蔽，但引号里"讨论禁词本身"仍会被算命中；
遇到提示先判断要不要改，别被工具牵着走。工具只负责筛，判定永远由盲解复查兜底。

它会查：LaTeX 结构（`$`/`$$` 成对、`\left...\right` 配对、花括号配对、`\begin/\end` 配对）、
每题是否给出"答案"、禁词（显然/易得/不难看出）、"同型"引用格式是否含年份与题号、
讲解每节是否缺"什么时候用"。跑完再人工，避免重复劳动。

## 四、数值验证手法（数学类最有效）

> **能算数就别靠眼睛。**

| 手法 | 适用 | 例子 |
|---|---|---|
| 回代原式 | 方程、隐函数、微分方程 | 求得 $y'(0)=-2$，代回原方程验证两边相等 |
| 特殊值 | 恒等式、极限、不等式 | 取 $x=0.1$ 算两边数值是否同阶 |
| 求导验证 | 不定积分、原函数 | 对结果求导，看是否回到被积函数 |
| 取极限/边界 | 单调性、最值 | 代入端点与临界点 |
| 极小样本 | 数列、组合、概率 | 取 $n=1,2,3$ 手算对照通项 |
| 反例搜索 | 全称命题、充分性 | 先试 $\lvert x\rvert$、$x^2\sin\frac1x$、分段函数 |
| 奇偶/量纲 | 函数性质、物理 | 检查对称性与单位 |

## 五、两种使用模式

### 模式 1：交付前自审（P4.5，必做）

顺序不能变：**先审讲解，再审详解，最后审复习路线**——详解的方法来自讲解，讲解错了详解会连着错；而复习路线会**复制讲解里的结论**，同一个错误会同时出现在多处。
审查时不要只搜"讲解里的那句话"，要按**结论关键词**在全部产物里搜一遍，确认没有别处复述了同一个错误。

1. 按天切块：一天一天审，审完修完再进下一天（避免大批量返工）。
2. 讲解：每节的例题盲解 → 对照 → 查 12 类清单 → 修。
3. 详解：不看讲解做题 → 对答案 → 查 10 类清单 → 修。
4. 只审 **S 级和 A 级**考点的内容先保证（B 级可以标"未审"）。
5. 产出 `审查报告.md`，**致命 = 0** 才能进 P5。

剩余时间不够时：至少审完 **S 级考点的讲解 + 对应的全部详解**，并在报告里写清哪些没审。

### 模式 2：复审已有内容（工作区里已经有 `ai_study/`）

适用于"内容已经生成过，现在要查"：

1. 如果没有考点清单，先按 `references/reverse-engineer.md` 反推一份（不用完整，能定 S/A 即可）。
2. 从 S 级开始，一级一级往下审。
3. **先出报告，再改文件**：一次性改容易越改越乱，且丢失原始证据。
4. 报告用增量方式，保留原行号引用，方便对照。

## 六、分级与判定标准

| 级别 | 判据 | 处理 |
|---|---|---|
| **致命** | 答案错 / 概念错 / 条件漏，导致学生会学错 | 必须改，改完重审该条 |
| **严重** | 推理不成立或漏情况，但最终答案恰好对 | 必须改；若课程不要求严谨，可标注"此处不严谨" |
| **轻** | 表述、记号、排版 | 记录，可选修 |
| **撤销** | 审查者自己算错 | 明确撤销并写原因，不许硬说 |

**误报比漏报更糟**：报错一条但其实是自己算错，会让学生对整个材料失去信任。所以每条都要求"我怎么验的"。

## 七、闭环

1. 每条 finding 必须有状态：待修 / 已修 / 撤销。
2. 改完必须**重跑那一题的盲解**——改错比不改更常见。
3. `审查报告.md` 留在 `ai_study/` 下，作为交付凭证；`check_coverage.py --strict` 会检查它。
4. 最终给用户的话里要有一句："讲解与详解已盲解复核，致命 0 条（严重 X 条已修）"。

## 八、自我欺骗清单（出现即停）

| 想法 | 实际 |
|---|---|
| "我读过一遍，没问题" | 你没算，所以没审 |
| "这一步是我推出来的，肯定对" | 生成者推出的步骤带着同样的误解 |
| "答案看着合理" | 看着合理正是错误答案的典型特征 |
| "这个细节不重要" | 学生学的就是细节 |
| "改起来太麻烦" | 交付错答案要付的代价更大 |
| "审查报告可以最后补" | 最后一定不补；先写报告再改 |

## 九、报告要求

见 `templates/审查报告.md`。最少包含：结论（各级别条数与可交付判定）、讲解问题表、详解问题表、机械扫描结果、**覆盖清单**、修复记录。

没有"覆盖清单"的报告一律视为未审——因为它无法证明审了多少。
